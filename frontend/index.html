    FAQ

    Do I need an API key?

    No. Only the AI assistant needs a Groq key. Without one it runs in offline mode.

    Where do I host it?

    Frontend on GitHub Pages or Vercel. Backend on Render or any Docker host.

    How do I change the admin password?

    Set ADMIN_PASSWORD and SECRET_KEY as environment variables before deploying.
