Frequently asked questions

Do I need an API key?

No. The analysis tools run in your browser. The AI assistant needs a key only when the site owner has not set one on the server; you can paste your own Groq, Gemini, Anthropic, OpenRouter or OpenAI key in the Assistant tab.

Where is my data stored?

Your inputs stay in your browser. Saved sessions live in this browser storage. A share link either carries your data inside the link, or, if you choose a short link, stores it on the server for 30 days.

Can I upload documents?

Yes. Files of type .txt, .md, .csv, .json, .html, .docx and .pdf are read in your browser and searched with BM25 ranking. PDFs need selectable text; scanned or image-only PDFs would need OCR, which is not supported, so paste the text instead.

How do I change the language?

Use the language selector in the footer to switch between English and Telugu. The interface is translated; tool results and AI answers appear in the language you ask in.

Where is it hosted?

On Vercel: static pages plus serverless functions for the AI proxy and optional short links.
