Frequently asked questions

Do I need an API key?

No. Analytics, ML, clustering, security tools and document search run in your browser. Only the AI features need an API key (Groq, Gemini, Anthropic, OpenRouter or OpenAI), which you can paste in the workspace.

Where do I host it?

The frontend runs on GitHub Pages. The optional backend runs on Render or any Docker host.

How do I change the admin password?

Set ADMIN_PASSWORD and SECRET_KEY as environment variables before deploying.
